## <sub><img src="./assets/icons/localization.svg" alt="" width="22" /></sub> Localization & Review

I contribute to software localization and linguistic review in **European Portuguese (pt-PT)**. My approach goes beyond literal translation:

- Natural and idiomatic European Portuguese — clearly distinguished from pt-BR
- UI and functional context before literal translation
- Consistent technical terminology and software conventions
- Proofreading, linguistic QA, accessibility and user-facing clarity
